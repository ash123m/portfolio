- **Live Website (GitHub Pages):** https://ash123m.github.io/poornaprajna-freshers-2026/

## Printable Poster QR Files
Ready-to-print QR assets pointing to `https://ash123m.github.io/poornaprajna-freshers-2026/` are included in `assets/`:
- `assets/poster-qr.png` (2000×2000 px high-resolution PNG)
- `assets/poster-qr.svg` (crisp vector SVG for large poster printing)
- `assets/poster-qr-card.png` (framed printable poster card with the official PIM logo and event details)

## GitHub Pages Setup
1. Open repository **Settings → Pages**.
2. Under **Build and deployment → Source**, select **GitHub Actions**.
3. Every push to `main` automatically deploys via `.github/workflows/deploy.yml`.

## Optional Personalized Greeting Link
Append `?name=FirstName` to the URL (for example, `https://ash123m.github.io/poornaprajna-freshers-2026/?name=Ananya`) to greet a specific fresher by name.
